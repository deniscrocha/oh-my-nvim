# Oh My Nvim

My custom nvim config

## LSPs

- Tsserver: `sudo npm -g install typescript-language-server`
- Clangd: `sudo pacman -S clang`
- LuaLs: `sudo pacman -S lua-language-server`
- TealLs: `luarocks install teal-language-server --local`
- Zls:
    `git clone https://github.com/zigtools/zls`
    `cd zls`
    `zig build -Doptimize=ReleaseSafe`
- Ocamllsp:
    Only install ocaml, the language instructions will tell you to install the lsp.
